# YE$! CHEF PRO

GitHub Pages files for the YE$! CHEF PRO kitchen costing app.

## Important after replacing files
If the old blue/old-logo version still appears on Samsung Chrome:
1. Open the GitHub Pages site.
2. Tap Chrome **⋮** → **Settings** → **Site settings** → **Stored data** (or delete the site data for the GitHub Pages address).
3. Reopen the site.
4. If it is installed on the home screen, remove the old shortcut and install YE$! CHEF PRO again.

The app uses a cache-safe build and a new `v6` manifest/icon version.
